# KinderLens Safety Principles

1. **Safety is a hard gate.** Unsafe vision results and unsafe generated text
   must not be shown as learning content.
2. **Grounding is a hard gate.** Explanations, quizzes, stories, and vocabulary
   meanings require trusted reference text.
3. **Ambiguity is disclosed.** Low-confidence or multi-object results request a
   clearer image instead of pretending certainty.
4. **Child language comes first.** Content should use simple words and explain
   necessary technical terms immediately.
5. **No raw photos in history.** Interaction history stores analyzed results,
   not uploaded image data.
6. **Language does not change facts.** English, Hindi, and Hinglish may change
   presentation, but not the grounded factual source.
7. **Parent visibility is required.** Learning activity should remain available
   through the protected Parent Dashboard.
8. **Failures are explicit.** Service, grounding, and validation failures must
   show a friendly recovery message and must not become invented content.
9. **Parent data controls are explicit.** History export and deletion require
   parent authentication and destructive actions require confirmation.
